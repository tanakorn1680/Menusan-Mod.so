# ProMenu 0.10.0

ปุ่มวงกลมลอย + แผงเมนูแบบสัมผัส สำหรับ GTA SA Android 2.10 (arm64, AML) รอบ 0.5 เพิ่มภาษาไทย (ยังไม่เคยทดสอบในเกมจริง)

## แท็บตอนนี้
- **Player:** ตั้งระดับตำรวจ 0–6, เลือด, เกราะ, เงิน (ปุ่ม −/+ และพรีเซ็ต)
- **Vehicle:** (0.10.0 ขยายใหญ่ ดูหัวข้อด้านล่าง) เครื่องมือรถ, สวิตช์รถ 8 ตัว, ความหนาแน่นรถ, ที่นั่ง, เสกตาม ID และรายการรถ 88 คัน แยก 5 หมวด (พับ/ขยายได้)
- **Weapon:** ทิ้ง/ถอดอาวุธที่ถืออยู่, ให้อาวุธ 39 แบบแยก 8 หมวด (ระยะประชิด ปืนพก ลูกซอง ปืนกลมือ ปืนยาว อาวุธหนัก อาวุธขว้าง อุปกรณ์) เลือกกระสุน 100/500/1000/9999 ถอดอาวุธทั้งหมด (แตะสองครั้ง) โหลดโมเดลอาวุธก่อนให้ แบบเดียวกับสูตรของเกม
- **Teleport:** วาร์ปไปจุดหมายที่ปักบนแผนที่, วาร์ปตามพิกัด X/Y, สถานที่ 10 แห่ง, จุดของฉัน 6 ช่อง (บันทึกไว้ข้ามการเปิดเกม), ตัวเลือกวาร์ปลงใต้น้ำ ทำงานเหมือนเมนู ARM เดิม (โหลดฉาก หาพื้น/ผิวน้ำ วาร์ป วางบนถนน)
- **Visual:** สวิตช์ 9 ตัวเขียนค่าแฟลกของเกมตรง ๆ แบบเมนู ARM เดิม: มองเห็นอินฟราเรด/กลางคืน, ฟิลเตอร์ความมืด, เอฟเฟกต์กล้องวิดีโอ/ลิฟต์, เอฟเฟกต์หมอก, แสดง HUD, แสดงเรดาร์, เรดาร์สีเทา
- **Game:** ซิงก์เวลากับเครื่อง, ความเร็วเกม, ตั้งชั่วโมง/นาที/ความยาววัน, วันในสัปดาห์, อากาศ (แดดจ้า/มีเมฆ/ฝน/หมอก/พายุฝน/พายุทราย/อัตโนมัติ), กล้องมุมสูง + ซูม
- **Cheats:** สูตรของเกมครบ 100 ตัว ลำดับเดียวกับ ARM CheatMenu เดิม จัด 12 หมวด
  - แตะครั้งแรก = เปิด แตะอีกครั้ง = ปิด มีข้อความ "Cheat NAME Activated/Deactivated"
  - ปุ่มที่มีสถานะจริงมีป้าย ON/OFF (อ่านจาก `m_aCheatsActive` ของเกม) สูตรแบบทำครั้งเดียวจบไม่มีป้าย
  - หมวด Danger ต้องแตะสองครั้ง
- **Menu:** เลือกภาษา English / ไทย, Overlay (FPS, พิกัด, เวลาเล่น, ตำแหน่ง 5 จุด, สี, ไล่สี RGB, ไม่มีพื้นหลัง), ตั้งค่าปุ่มลอย และข้อมูลวินิจฉัย

## ภาษาไทย
- Menu → Language → ไทย แปลทั้งเมนู ชื่อสูตร 100 ตัว และหมวด ชื่อรถยังเป็นภาษาอังกฤษ
- ต้องมีฟอนต์ไทย ปลั๊กอินหาเองจากโฟลเดอร์ฟอนต์ของ Android (ไฟล์ชื่อมีคำว่า Thai) หรือใช้ไฟล์ของคุณที่ `Android/data/com.rockstargames.gtasa/files/ProMenu/font_th.ttf` ถ้าไม่เจอ ปุ่มไทยจะกดไม่ได้
- ImGui ไม่ประกอบสระ/วรรณยุกต์ซ้อนกัน บางคำอาจเห็นเครื่องหมายชิดหรือทับกันเล็กน้อย

## เพิ่มใน 0.10.0 (แท็บ Vehicle)
ทุกฟังก์ชันถอดจากโค้ดของเมนู ARM เดิม (`VehiclePage::Draw/SpawnVehicle`, `Util::FlipCar/GetClosestCar`) ทั้งออฟเซ็ต หมายเลขคำสั่งสคริปต์ และตำแหน่งแพตช์ ยังไม่เคยทดสอบในเกมจริง
- **Vehicle tools:** Fix vehicle (เรียก `Fix` ตามชนิดรถ + เลือด 1000), Flip vehicle (สคริปต์ผ่าน SAUtils), No burn on flipped (NOP 2 คำสั่งในเกม ตรวจไบต์ก่อนเสมอ เกมรุ่นอื่นจะไม่ถูกแตะ และจำค่าไว้ใน `config.txt`), Stay on bike, Perfect handling (ธง STRONGGRIP)
- **Vehicle options** (ต้องเป็นคนขับ): Always Skidmarks, Engine State, No Particles, Comedy Control (เฉพาะรถยนต์/ควอด/มอเตอร์ไซค์/BMX), HS Targetted, Invisible Car, Lights State, Lock Door
- **Traffic:** Vehicle Density Multiplier 0–10
- **Switch seats / Enter near vehicle:** แสดงชื่อรุ่น (เช่น copcarvg) และจำนวนที่นั่ง ปุ่ม Driver / Passenger 1..N วาร์ปเข้าที่นั่งของรถคันที่นั่งอยู่หรือคันที่ใกล้สุด
- **Spawn by ID:** As driver / In Air + เลือกเลขรุ่น 400–611 (ลูกศรวนรอบ) ปุ่ม Spawn (รถไฟ/รถราง ปิดไว้เหมือนเดิม)
- Flip, ที่นั่ง, เสกตาม ID และ Lights State ต้องใช้ม็อด SAUtils
- รายละเอียดทางเทคนิคและงานที่เหลืออยู่ใน `PROGRESS_HANDOFF.txt`

## 0.9.3 (ตรวจหาสาเหตุที่ทิ้งอาวุธแล้วไม่มีของบนพื้น)
หน้า Weapon มี 2 อย่างใหม่ใต้ปุ่มทิ้ง/ถอด:
- **ข้อความผลล่าสุด** บอกอาวุธ โมเดล กระสุน หมายเลขของเก็บ (pickup handle) และพิกัดตัวละคร/จุดที่วาง
- **สวิตช์ "ทดสอบ: สร้างของเก็บแต่ไม่ถอดอาวุธ"** เปิดแล้วกดทิ้ง จะสร้างของเก็บแต่ยังถืออาวุธอยู่ ใช้แยกว่าปัญหาอยู่ที่การสร้างของเก็บหรือที่การถอดอาวุธ

## แก้ไขใน 0.9.2 (ทิ้งอาวุธแล้วไม่มีของบนพื้น)
สาเหตุ: 0.9.1 เรียกฟังก์ชันสร้างของเก็บของเกมตรง ๆ โดยไม่ตรวจว่าสร้างสำเร็จ เมนู ARM เดิมไม่ได้ทำแบบนั้น แต่สั่งงานผ่าน SAUtils เป็นคำสั่งสคริปต์ 4 ขั้น (ถอดรหัสจากไฟล์เดิมได้เป๊ะ):
1. `04C4` หาจุดที่อยู่หน้าตัวละคร 3.0 หน่วย 2. `0781` หาโมเดลของอาวุธ 3. `032B` สร้างของเก็บ (ชนิด 3, กระสุนเท่าที่ถืออยู่) 4. `0555` ถอดอาวุธจากตัวละคร
0.9.2 ทำตามนี้ทุกขั้น และ**ถอดอาวุธก็ต่อเมื่อของเก็บถูกสร้างจริง** (ถ้าขั้นไหนพลาด อาวุธยังอยู่กับตัว) ต้องมีม็อด SAUtils (ตัวเดียวกับที่เมนู ARM เดิมต้องใช้) ถ้าไม่เจอ ปุ่มจะกดไม่ได้และมีข้อความบอก ดูขั้นตอนใน `last_action.txt`

## แก้ไขใน 0.9.1
- **ปุ่มถอดอาวุธทั้งหมด:** ตอนนี้อ่านช่องอาวุธของตัวละครก่อน ถ้าไม่มีอาวุธจะไม่เรียกเกมเลย (ขึ้นว่า "ยังไม่มีอาวุธ") ถ้ามีจะถอดทีละกระบอก
- **ใหม่:** ปุ่ม "ทิ้งอาวุธที่ถืออยู่" (วางเป็นของเก็บได้ข้างหน้าตัวละคร 2.5 หน่วย แล้วค่อยถอดจากตัวละคร ถ้าสร้างของเก็บไม่สำเร็จจะไม่ถอด) และ "ถอดอาวุธที่ถืออยู่"
- breadcrumb ใน `last_action.txt` ครอบคลุมสูตร, การเรียกรถ, ถอด/ทิ้งอาวุธด้วย
- ล็อกที่ส่งมา (ตายใน `CVehicleAnimGroup::ComputeAnimDoorOffsets` ← `CPlayerInfo::Process`) เป็นตรรกะ "เดินเข้าใกล้รถแล้วเกมหาประตูรถ" ของเกมเอง ไม่มีเฟรมของ ProMenu ในสแต็ก ยังยืนยันไม่ได้ว่าปุ่มถอดอาวุธเป็นต้นเหตุ ถ้าเกมเด้งอีก ให้ส่ง `previous_session.txt` มาดูว่าขั้นตอนสุดท้ายของเมนูคืออะไร

## เพิ่มใน 0.9
แท็บ Weapon และ Visual ใหม่ ต่อยอดจาก 0.8 ของคุณ (SafeMem, diag ใช้ครบ: อ่านค่าสวิตช์ผ่าน SafeMem 4 ครั้ง/วินาที, ขั้นตอนให้อาวุธมี breadcrumb ใน `last_action.txt`) ยังไม่ได้ทำ: Keep fog on low graphic และ Invisible water ของเดิม (ใช้ hook ของตัวเอง)

## แก้ไขใน 0.8 (เกมหลุดตอนกดวาร์ป)
ล็อกจาก crash บอกว่าเกมตายใน hook ที่วาดเมนู (`DebugDisplayTextBuffer` → ProMenu) ไม่ใช่ตอนสั่งวาร์ปจริง จุดเดียวที่โค้ดเดิมอ่านหน่วยความจำเกมดิบ ๆ ทุกเฟรมเมื่อเปิดแท็บ Teleport คือ `GetWaypoint` (เดินตาราง blip ของแผนที่โดยเชื่อว่า `CRadar::ms_RadarTrace` เป็นพอยน์เตอร์เสมอ) ถ้าเลย์เอาต์ในเกมต่างไปแม้นิดเดียวเกมจะตายทันที
- ใหม่ `jni/safemem.h`: อ่านหน่วยความจำเกมผ่านเคอร์เนล (`write()` ลง pipe) ถ้าพอยน์เตอร์ผิดจะได้ `false` แทน SIGSEGV ใช้กับ waypoint, ตำแหน่งตัวละคร/รถ, ค่าเลือด/เกราะ/เงิน
- `GetWaypoint` ตรวจพอยน์เตอร์และตารางก่อน รองรับทั้งแบบ "พอยน์เตอร์ชี้ตาราง" และ "ตารางอยู่ที่ symbol เลย" อ่านที่ 4 ครั้ง/วินาทีแทนทุกเฟรม และเมนู About แสดง `Radar table: ...` ว่าเจอแบบไหน
- `DoTeleport`: เช็กพิกัด (NaN/นอกแผนที่), กันเรียกซ้อน, ไม่ยัด `CAutomobile::Teleport` ใส่เรือ/รถไฟอีกต่อไป (หา `Teleport` ของรถคันนั้นจาก vtable ถ้าเป็นรถที่ไม่รองรับจะขึ้นข้อความแล้วไม่ทำอะไร), ส่ง out-pointer จริงให้ `GetWaterLevelNoWaves`, เรียก `Teleport` ให้ถูกทั้งสองแบบ calling convention
- คิวคำสั่ง UI → เกมใช้ release/acquire (เดิมใช้ `volatile` ซึ่งบน ARM ไม่การันตีลำดับการเขียน) และกดวาร์ปรัว ๆ ระหว่างโหลดจะถูกข้าม
- ใหม่ `jni/diag.h`: เขียน breadcrumb ของแต่ละขั้นวาร์ป/การเปลี่ยนแท็บลง `Android/data/com.rockstargames.gtasa/files/ProMenu/last_action.txt` (ของรอบก่อนเก็บเป็น `previous_session.txt`) ถ้ายังเด้งอยู่ ไฟล์นี้บอกว่าตายที่ขั้นไหน
- Actions อัปโหลด `libProMenu64-symbols` (ไฟล์ไม่ตัด symbol) เพิ่มอีกตัว ใช้แปลง offset ใน crash log เป็นชื่อฟังก์ชัน: `llvm-addr2line -f -C -i -e libProMenu64.so 0x2b69c`
